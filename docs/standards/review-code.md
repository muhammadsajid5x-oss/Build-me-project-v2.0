# Prompt 7 — Review Code
## Prompt
> Review this code. Look for bugs, security problems, performance problems, duplicated code, poor design, missing validation and missing tests. Give me the problems first. Do not rewrite the code yet.
## Purpose
Use this prompt for AI-assisted code review before human review and merge.
## Review Areas
- Bugs
- Security
- Performance
- Duplicate code
- Design quality
- Validation
- Error handling
- Tests
- Maintainability
- Accessibility where applicable
- Type safety
## Rule
AI review does not replace human code review.
## Workflow
Code → AI Review → Human Review → Fix → Test → CI
