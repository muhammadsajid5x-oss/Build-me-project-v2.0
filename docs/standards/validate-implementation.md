# Prompt 11 — Validate Implementation
## Prompt
> Check this implementation against the original requirement. Create a checklist showing what is complete, what is missing and what needs fixing.
## Purpose
Use this prompt to validate the implementation against the original requirement and expected outcome.
## Validation Areas
- Requirement
- Acceptance criteria
- Functionality
- Tests
- Security where applicable
- Performance where applicable
- Analytics where applicable
- User or outcome validation where applicable
## Rule
AI validation is an aid. Actual validation evidence must be reviewed by the Technology Owner.
## Workflow
Implementation → Validate → Fix → Re-test → Approve
