# Prompt 12 — Prepare Deployment
## Prompt
> Check this feature before deployment. Give me a simple checklist for build, tests, environment variables, security, database changes, analytics, monitoring, rollback and deployment.
## Purpose
Use this prompt to prepare a feature for controlled deployment.
## Deployment Checklist Areas
- Build
- Automated tests
- Environment variables
- Security
- Database changes
- Analytics
- Monitoring
- Rollback
- Deployment process
## Rule
Never expose secrets while preparing deployment information.
Deployment must follow the project's approved CI/CD and release controls.
## Workflow
Validate → Deployment Check → CI/CD → Deploy → Monitor
