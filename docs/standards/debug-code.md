# Prompt 6 — Debug Code
## Prompt
> Help me find the cause of this problem. Do not change the code yet. Explain the likely cause, what I should check, and the safest fix.
## Purpose
Use this prompt when something breaks.
## Required Context
Provide:
- What was expected
- What actually happened
- Error message
- Relevant code
- Steps to reproduce
- What has already been tried
## Rule
Find and understand the likely cause before changing code.
## Workflow
Problem → Investigate → Explain Cause → Choose Fix → Implement → Test
