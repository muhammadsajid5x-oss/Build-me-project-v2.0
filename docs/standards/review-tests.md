# Prompt 10 — Review Tests
## Prompt
> Review these tests. Tell me what important behaviour is not tested. Check whether the tests are reliable and easy to understand.
## Purpose
Use this prompt to identify gaps and weaknesses in existing automated tests.
## Review Areas
- Missing behaviour
- Weak assertions
- Missing edge cases
- Missing error cases
- Duplicate tests
- Test reliability
- Test readability
- Maintainability
- Regression coverage
## Rule
The Technology Owner decides whether test coverage is sufficient.
## Workflow
Tests → AI Review → Human Review → Improve → Execute
