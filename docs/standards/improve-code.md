# Prompt 8 — Improve Code
## Prompt
> Improve this code while keeping the same behaviour. Follow Clean Code, SOLID, DRY and KISS. Explain what you changed and why.
## Purpose
Use this prompt to improve maintainability and code quality without intentionally changing existing behaviour.
## Quality Principles
- Clean Code
- SOLID
- DRY
- KISS
- Maintainability
- Readability
## Rule
Improvements must preserve correct behaviour and must be tested.
## Workflow
Review → Improve → Test → Validate
