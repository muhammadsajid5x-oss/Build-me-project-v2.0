# Child Story Requirement-Understanding Prompt

## Purpose

Use this prompt as the first planning step for every Child Story. It helps the team understand user outcomes, system behavior, and delivery considerations before technical planning or implementation begins.

## Reusable Prompt

> Read this Child Story. Explain it in very simple words. Tell me the user outcome, system behaviour, data needed, technical dependencies, API needs, database needs, analytics needs, security needs, performance needs, testing needs and deployment needs. Tell me what is unclear. Do not write code yet.

## Input

Paste the complete Child Story, including its acceptance criteria and any available parent Epic context, below the prompt.

## Expected AI Response

The response should clearly cover:

1. A plain-language explanation of the Child Story.
2. The user outcome and observable successful result.
3. The required system behavior.
4. Data needed, produced, stored, or accessed.
5. Technical dependencies and affected components.
6. Whether API work is needed and what it involves.
7. Whether database work is needed and what it involves.
8. Analytics events, properties, and success measures needed.
9. Security, privacy, authentication, and authorization considerations.
10. Performance expectations and constraints.
11. Testing required to verify the acceptance criteria and non-functional needs.
12. Deployment, migration, configuration, and rollout needs.
13. Unclear requirements, assumptions, risks, and questions that need answers.

The AI must not produce code. Unanswered questions and assumptions must be reviewed by the responsible people before implementation planning proceeds.
